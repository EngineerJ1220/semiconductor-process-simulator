# Semiconductor Process Simulator

스퍼터 공정 관계를 단순화한 합성 Lot 데이터를 생성하고, 사용자 진단·규칙 기반 탐지·Random Forest 분류 결과를 실제 발생 조건과 비교하는 교육용 프로젝트입니다.

## v2.4.1 주요 변경 사항

- `새 랜덤 문제`와 `재현 번호로 다시 풀기`를 분리했습니다.
- 새 랜덤 문제를 누를 때마다 재현 번호가 자동으로 바뀌어 같은 문제가 반복되지 않습니다.
- 쉬움은 Lot 3~5, 보통은 Lot 3~7 중 무작위 시점부터 이상이 시작됩니다.
- Lot 1~2 이후에도 정상 Lot이 이어질 수 있어 Lot 3이 반드시 이상은 아닙니다.
- 전원 출력·Ar 유량·챔버 압력 이상은 두께 상승과 하락을 같은 확률로 생성합니다.
- 타겟 상태 변화는 일반적인 마모를 반영해 하락을 더 자주 생성하지만 과보상에 의한 상승도 포함합니다.
- AI 학습 데이터에도 동일한 이상 시작 범위와 방향 생성 규칙을 적용했습니다.

## 난이도별 초기 Lot 규칙

- 쉬움: Lot 1~2 정상 기준, 이상 시작 Lot 3~5
- 보통: Lot 1~2 정상 기준, 이상 시작 Lot 3~7
- 어려움: 초기 정상 상태 미보장, 이상 시작 Lot 1~6
- 전문가: 초기 정상 상태 미보장, 이상 시작 Lot 1~8

## 버튼 사용법

- 새 랜덤 문제: 매번 새로운 재현 번호와 공정 이상 조건 생성
- 재현 번호로 다시 풀기: 입력한 번호의 동일 문제 재생성
- 다음 Lot 생산: 현재 문제의 다음 Lot 데이터 생성

## 모델 범위

현재 AI는 Random Forest 분류 모델입니다. 합성 데이터에서 정상과 네 가지 공정 이상 원인을 분류하며, 실제 Fab 성능을 의미하지 않습니다.
