# Semiconductor Process Simulator

DC 마그네트론 스퍼터 공정을 단순화한 합성 Lot 데이터를 생성하고, 이상 시점과 원인을 진단하는 교육용 웹 애플리케이션입니다. 사용자의 진단, 규칙 기반 탐지와 Random Forest 분류 결과를 각각 실제 발생 조건과 비교합니다.

실행 중인 앱: https://semiconductor-process-simulator-j.streamlit.app/

## 다루는 문제

사용자 문제에서는 `다음 Lot 생산`을 눌러 Lot을 순차적으로 생성하고 공정 변화를 분석합니다. 각 Lot에는 웨이퍼 25장의 데이터가 포함되며, Power·Ar Flow·Pressure의 설정값과 실제값, 증착률, 두께, 균일도와 예상 면저항을 확인할 수 있습니다.

사용자 문제에는 다음 네 가지 이상 원인 중 하나가 무작위 시점부터 주입됩니다.

| 원인 | 데이터에 나타날 수 있는 변화 |
| --- | --- |
| 전원 출력 제어 이상 | 실제 Power가 설정값에서 벗어나며 증착률·두께·예상 면저항이 함께 변화 |
| Ar 유량 제어 이상 | 실제 Ar Flow가 설정값에서 벗어나고 Pressure와 플라즈마 상태가 변하며 두께·균일도에 영향 |
| 챔버 압력 제어 이상 | 실제 Pressure가 설정값에서 벗어나며 증착률·두께·균일도·예상 면저항이 변화 |
| 타겟 상태 변화 | 주요 제어값은 설정값 부근이지만 증착률과 박막 특성이 점진적으로 변화 |

이상의 크기, 노이즈, 신호 중첩, 센서 편향, 보상 제어와 간헐 발생 여부는 난이도에 따라 달라집니다.

| 난이도 | 초기 정상 Lot | 이상 시작 Lot | 특징 |
| --- | --- | --- | --- |
| 쉬움 | Lot 1·2 보장 | Lot 3–5 | 단일 원인, 강한 신호 |
| 보통 | Lot 1·2 보장 | Lot 3–7 | 신호 중첩, 일시적 변동 |
| 어려움 | 미보장 | Lot 1–6 | 약한 이상, 센서 편향, 일부 웨이퍼만 이상 |
| 전문가 | 미보장 | Lot 1–8 | 복합 이상, 간헐 현상, 보상 제어, 높은 노이즈 |

AI 학습용 데이터에서 한 Case는 8–13개 Lot으로 구성됩니다. 학습·평가 데이터에는 약 15%의 정상 Case도 포함해 이상이 없을 때의 오탐률을 함께 측정합니다.

## 설계에서 신경 쓴 부분

- **평가 단위 분리** — 학습과 평가를 Lot이 아닌 Case 단위로 나눕니다(`GroupShuffleSplit`). 같은 Case의 Lot이 양쪽에 섞이면 성능이 실제보다 높게 측정될 수 있습니다.
- **지름길 학습 차단** — 난이도 라벨은 실제 Fab 데이터에 존재하지 않으므로 모델 입력에서 제외합니다. 앱에는 난이도를 입력한 비교 모델과의 정확도 차이도 함께 표시합니다.
- **기준 Lot 가정 검증** — 어려움과 전문가 난이도는 Lot 1부터 이상이 시작될 수 있습니다. 초기 Lot이 항상 정상이라는 가정에 기대지 않았을 때의 성능을 별도로 측정합니다.
- **학습에 없던 원인 평가** — 증착 시간 과다, 두께 측정 장비 편향, 기판 온도 이상과 셔터 동작 이상은 학습 데이터에 넣지 않고 평가에만 사용합니다. 모델이 이상을 탐지하는지, 원인 판단을 유보하는지, 학습된 네 원인 중 하나로 잘못 단정하는지를 나눠서 확인합니다.
- **정상 Case 포함** — 이상이 없는 Case를 학습·평가 데이터에 포함해 정상 공정을 이상으로 판단하는 비율을 함께 측정합니다.

## 표시하는 지표

정확도와 Macro F1, 난이도별 성능, 이상 Lot 정확 일치율과 ±1 Lot 이내 탐지율, 정상 Case 오탐률, 1·2순위 원인 적중률과 혼동 행렬을 표시합니다.

학습에 없던 원인에 대해서는 다음 세 지표를 따로 표시합니다.

- 이상 탐지율
- 탐지 후 원인 판단 유보율
- 학습된 원인 중 하나로 단정한 비율

사용자 풀이 기록은 이상 시작 Lot, 주요 원인과 추가 원인의 정답률로 집계하며, AI 분석을 실행한 문제는 AI 결과와 별도로 비교합니다.

## 풀이 기록 보존

풀이 기록은 `st.session_state`에 저장되므로 페이지를 새로 고치거나 Streamlit Cloud 앱이 재시작되면 사라질 수 있습니다.

앱에서 풀이 기록 CSV를 다운로드할 수 있으며, 다음 접속 때 같은 CSV를 다시 불러오면 현재 세션의 기록과 중복 없이 이어 붙일 수 있습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 한계

- 스퍼터 공정의 물리 관계를 단순화한 합성 데이터이며 실제 기업의 Recipe나 생산 데이터를 사용하지 않았습니다.
- 표시되는 성능은 시뮬레이터가 생성한 미사용 Case에 대한 결과이므로 실제 Fab에서의 진단 성능을 의미하지 않습니다.
- 학습된 원인 후보는 네 가지이며 실제 공정에서 발생할 수 있는 원인은 이보다 훨씬 많습니다.
