# Semiconductor Process Simulator

## 핵심 검증

이 프로젝트의 목표는 합성 데이터에서 높은 정확도를 만드는 데 그치지 않고, **AI가 어떤 가정에 기대고 언제 틀리는지 확인하는 것**입니다.

1. 실제 Fab에서 알 수 없는 `문제 난이도`를 AI 입력 변수에서 제거하고, 같은 데이터 분할에서 난이도를 넣은 비교 모델과 정확도 차이를 측정합니다.
2. 이상이 Lot 1 또는 Lot 2부터 시작하는 문제를 학습·평가해, 처음 두 Lot이 항상 깨끗한 정상 기준이라는 가정을 없앴습니다.
3. 증착 시간 과다, 두께 측정 장비 편향, 기판 온도 이상, 셔터 동작 이상은 학습 클래스에 넣지 않고 별도 시험해 원인 판단 유보가 실제로 작동하는지 확인합니다.
4. 전원 출력, Ar 유량, 챔버 압력과 타겟 보상 상태에 따라 두께가 감소할 수도 증가할 수도 있도록 데이터 생성 규칙을 수정했습니다.

## 프로젝트 개요

교육용 합성 데이터를 이용해 Sputter 공정의 이상 시점과 원인을 진단하는 Streamlit 웹 애플리케이션입니다. 사용자가 먼저 데이터를 분석해 진단을 제출한 뒤, AI·통계 기준·실제 발생 조건과 결과를 비교합니다.

## v2.3.0 주요 변경 사항

- AI 입력 변수에서 쉬움·보통·어려움·전문가 난이도 제거
- 동일 분할에서 난이도 포함 모델과 제거 모델의 성능 비교
- Lot 1·Lot 2부터 시작되는 초기 이상 데이터 추가
- 목표 두께와 Recipe 설정값 중심 특징 추가
- 학습에 없던 네 가지 원인으로 판단 유보 검증
- 미지 원인 이상 탐지율, 판단 유보율, 과신 비율 표시
- 전원·유량·압력 이상을 상승과 하락 양방향으로 생성
- 타겟 보상 과도 시 두께가 증가할 수 있는 조건 추가
- 초기 이상과 정상 기준 확보 후 이상을 별도로 평가
- 혼동행렬과 원인별 오분류를 확인하는 화면 유지

## 사용 순서

1. 증착 재료와 문제 난이도를 선택합니다.
2. 새 문제를 시작합니다.
3. 정상 기준이 있는 문제는 Lot 2개 생산 후 이상 상황을 설정합니다.
4. 첫 Lot부터 이상인 문제는 Lot 생산 전에 이상 상황을 설정합니다.
5. Lot을 추가 생산하며 데이터를 분석합니다.
6. 사용자 진단을 제출합니다.
7. 사용자, AI, 통계 기준과 실제 발생 조건을 비교합니다.

## AI 사용 방식

AI는 힌트를 미리 제공하지 않습니다. 사용자가 진단을 제출한 뒤 동일한 데이터를 독립적으로 분석한 결과를 공개합니다. 문제 난이도는 모델 입력이 아니라 성능을 나누어 보는 평가 기준으로만 사용합니다.

## 한계

- 실제 기업 Recipe나 생산 데이터를 사용하지 않은 교육용 합성 데이터입니다.
- 합성 규칙을 바꾸면 모델 성능도 달라집니다.
- Random Forest의 예측 확률은 미지 원인을 완벽하게 식별하는 확률이 아닙니다.
- 학습에 없는 원인에서도 기존 원인을 과도하게 확신할 수 있으므로 판단 유보율과 과신 비율을 함께 확인합니다.
- 표시되는 성능은 실제 Fab 적용 성능을 의미하지 않습니다.
