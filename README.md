# Semiconductor Process Simulator

교육용 합성 데이터를 이용해 Sputter 공정의 이상 시점과 원인을 진단하는 Streamlit 웹 애플리케이션입니다.

## v2.2.0 주요 변경 사항

- 첫 화면에 사용 방법을 바로 표시
- 전체 화면을 1~8단계로 재구성
- 사용자가 먼저 진단한 뒤 AI 결과를 공개하도록 변경
- AI 모델 학습 화면을 사용자 풀이 과정에서 분리
- 사용자, AI, 통계 기준, 실제 발생 조건 비교표 추가
- AI 예측과 함께 확인된 주요 데이터 변화 표시
- 전체 한글 표현과 버튼 문구 개선
- 누적 기록에 사용자와 AI 정확도를 함께 표시

## 사용 순서

1. 증착 재료와 문제 난이도를 선택합니다.
2. 새 문제를 시작합니다.
3. 정상 Lot을 2개 생산합니다.
4. 이상 상황을 발생시킵니다.
5. Lot을 추가 생산하며 데이터를 분석합니다.
6. 사용자 진단을 제출합니다.
7. 사용자, AI, 통계 기준과 실제 발생 조건을 비교합니다.

## AI 사용 방식

AI는 힌트를 미리 제공하지 않습니다. 사용자가 진단을 제출한 뒤 동일한 데이터를 독립적으로 분석한 결과를 공개합니다. 기본 AI 모델은 첫 진단 제출 시 자동으로 준비됩니다.

## 주의

실제 기업의 공정 조건이나 생산 데이터를 사용하지 않은 교육용 합성 데이터 시뮬레이터입니다. AI 성능은 이 시뮬레이터가 생성한 미사용 합성 문제에 대한 결과이며 실제 생산 라인의 진단 성능을 의미하지 않습니다.
