# Semiconductor Process Simulator

스퍼터 공정의 관계를 단순화한 합성 Lot 데이터를 생성하고, 사용자의 공정 진단과 규칙 기반 탐지 및 Random Forest 분류 모델의 판단을 실제 발생 조건과 비교하는 교육용 웹 애플리케이션입니다.

## v2.4.0 주요 변경 사항

- `이상 발생` 버튼 제거
- 새 문제를 시작할 때 이상 원인과 시작 Lot을 내부에서 자동 설정
- 쉬움·보통은 Lot 1~2를 정상 기준 Lot으로 자동 생성
- 쉬움·보통의 이상은 Lot 3 이후부터 시작
- 어려움·전문가는 초기 정상 상태를 보장하지 않고 Lot 1부터 이상 가능
- 난이도별 초기 Lot 조건을 문제 설정과 분석 화면에 명확히 표시
- 사용자 판단과 실제 발생 조건을 항목별로 직접 비교
- 통계 기준 탐지 결과와 AI 분석 결과를 별도 영역으로 분리
- 프로젝트의 합성 데이터, 규칙 기반 탐지, 머신러닝 분류 구조 설명 추가

## 사용 순서

1. 증착 재료와 문제 난이도를 선택합니다.
2. 새 문제 시작을 누릅니다.
3. 쉬움·보통에서는 정상 기준 Lot 1~2가 자동 생성됩니다.
4. 다음 Lot 생산을 누르며 공정 변화를 분석합니다.
5. 어려움·전문가는 Lot 1부터 이상이 포함될 수 있습니다.
6. 사용자 진단을 제출하고 실제 발생 조건과 비교합니다.
7. 필요할 때만 AI 분석 결과를 확인합니다.

## 프로젝트 구조

- 합성 데이터 생성: 공정 관계를 단순화한 계산식과 난수
- 규칙 기반 탐지: 관리 범위와 변화 임계값을 이용한 이상 시점 탐지
- 머신러닝: Random Forest 분류 모델을 이용한 정상·이상 원인 예측
- 현재 회귀 모델은 사용하지 않음
- AI 성능은 합성 데이터에 대한 결과이며 실제 Fab 성능을 의미하지 않음
